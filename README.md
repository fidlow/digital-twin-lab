# Цифровой двойник лабораторной установки

Демонстрационный React-прототип для НТТС ФТИ: потоковая телеметрия, сценарии отказов,
объяснимая диагностика, индекс риска и журнал событий.

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite откроет локальный адрес вида:

```bash
http://localhost:5173
```

## Сборка

```bash
npm run build
npm run preview
```

## Что внутри

- `src/App.jsx` — основной React-компонент прототипа.
- `src/main.jsx` — точка входа.
- `src/index.css` — Tailwind CSS.
- `package.json` — зависимости и команды запуска.
- `tailwind.config.js`, `postcss.config.js` — конфигурация Tailwind.
